PROJECT PLAN
Projects & Planning > Project plan first lists accessible projects with their code,
stage, current project status and visible activity progress. Click Open project plan.
The selected project alone supplies activities, summary, planned/actual effort,
completion and overdue status. Other projects' activities are never combined here.
Switch via the project dropdown or Choose another project. Existing project-detail
Open project plan / company View plan links open that exact project/company.
Reset filters clears company/module/person/status/date filters while retaining project.
The project current status is from Project Master; activity status/progress come from
saved task status/completion and actual records, subject to existing access rights.
Plan activity and Edit plan keep a fixed project choice and save against that project.
Company choices belong to that project; other existing activity checks are preserved.
Export plan uses only the selected project's currently filtered activities.

SCOPED EXCEL IMPORT

No baseline/task/actual/calendar records are moved or deleted by this update.
Workspace-wide performance/reporting views remain available through their own menus.
