MY PROJECT MANAGEMENT v32 (32.0.0) -- USER MANUAL AND PROCESS FLOW
Release: 22-Nov-2026, Qatar. Previous app: v31.

INSTALL IN IIS
1. Back up application files and SQL database, then stop MyProjectManagement pool.
2. If already on v31 with its SQL patch installed, no further SQL change is needed.
   If upgrading from v30 or earlier, apply database/Database-HoursOnly-v31.sql
   against MyProjectManagement (or the cumulative Database-Upgrade-v32.sql).
3. Copy the CONTENTS of this package's publish folder into the existing folder:
   C:\inetpub\wwwroot\MyProjectManagement-IIS-SQLServer2022-2025\publish
   Preserve appsettings*.json, web.config, Keys and external key storage.
   The update package excludes runtime configuration and authentication keys.
4. Restart pool, sign in and Ctrl+F5. Confirm Version 32.

OPEN THE MANUAL
In the sidebar choose User manual & process flow. All roles can read the manual.
The page has an embedded guide plus PDF, Word, process-flow and full-guide links.
Documentation contains operating examples only, not current company data.
The same files are included under documentation/ in this ZIP and publish/wwwroot/
manual/. Open documentation/index.html locally or read the PDFs / Word files.
