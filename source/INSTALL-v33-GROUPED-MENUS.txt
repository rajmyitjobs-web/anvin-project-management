IIS UPDATE
1. Back up site files and database; stop MyProjectManagement application pool.
2. No SQL change if the v31 reporting patch is already installed.
   From v30 or earlier apply database/Database-HoursOnly-v31.sql or the cumulative
   Database-Upgrade-v33.sql against MyProjectManagement before restarting.
3. Copy CONTENTS of the package publish folder into your existing publish folder:
   C:\inetpub\wwwroot\MyProjectManagement-IIS-SQLServer2022-2025\publish
   Preserve appsettings*.json, web.config, Keys and external authentication keys.
   The update ZIP excludes runtime configuration and authentication keys.
4. Restart the pool, sign in, Ctrl+F5. Confirm Version 33.

Click a heading to expand/collapse it, or focus it and press Enter/Space.
The group containing the active screen opens automatically. Groups with no menu
items visible to the current login are hidden. This groups existing menu entries;
it does not grant rights or add previously hidden menu items. Choices persist in
the current page session. The actual forms, records, calculations and permissions
are unchanged. Chapter 19 of the included v33 manual shows the new menu map.
