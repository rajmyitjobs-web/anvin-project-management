NEW TEMPLATE
Only 15 non-AMC columns are present:
Project Code, Project Name, Customer Code, Project Type, Project Manager,
Project In-charge, Company, Module, Primary Consultant, Additional Consultants,
Project Start, Target Finish, Industry, Client Contact, Client Mandays.
Row 2 has Project Type prefilled as implementation. Fill its remaining required
fields, and copy implementation into the Project Type cell of each added row.
There are NO AMC date/cycle/hour/attendee fields or AMC reference sheets.
Company blank defaults Company 1. Project dates blank default today in preview.
Code max 50, name max 90. Employee references accept active ID/name/email.
Additional Consultants uses semicolon-separated employees. Module may be General.
Repeat project code and common fields for multiple company/module rows.
No existing projects are overwritten. Add-only, 1–500 rows / 5 MB, no formulas.
Keep codes as text to retain leading zeros. Fill the FIRST worksheet only.
